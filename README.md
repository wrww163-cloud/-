# 班级宠物园（可直接下载运行）

一个纯前端单页应用（HTML/CSS/JS），用于把班级管理变成可视化养成游戏：
- 班级档案管理（最多 20 班）
- 学生管理（每班最多 100 人）
- 神兽分配（随机 / 自选）
- 喂养升级与积分成长
- 班级积分排行榜

## 1. 快速运行

### 方式 A：直接双击打开（最简单）
在本地下载后，直接打开 `index.html` 即可使用。

### 方式 B：本地静态服务（推荐）
```bash
python3 -m http.server 4173
```
然后浏览器访问：
`http://127.0.0.1:4173`

## 3. 使用说明

### 页面切换
顶部按钮可在以下页面间切换：
1. 班级档案
2. 喂养中心
3. 积分排名
4. 系统设置

### 批量导入学生（当前班级）
在“班级档案”页，输入框中每行一个学生名。

示例：
```text
王小明
李小萌
陈天天
```

### 批量导入班级 + 学生档案
在“班级档案”页按以下格式导入：

```text
班级名:学生1,学生2,学生3
```

示例：
```text
一年级1班:王小明,李小萌
一年级2班:陈天天,赵星河
```

## 4. 数据存储

数据保存在浏览器 `localStorage`（键名：`class-pet-park-v1`）。
- 关闭浏览器后数据仍会保留
- 清空浏览器站点数据后会重置
